# PULSE ONE

Native iPhone-App (Swift, SwiftUI, später RealityKit) für Gesundheit, Sport und Regeneration. **ONE BODY. MANY WORLDS.**

- `apps/PulseOne/` – die App; Kernlogik in `Packages/PulseCore`
- `docs/pulse-one-coordination/` – Kanal mit Codex: Direktive, Aufträge, Antworten, Status, Belege
- `.github/workflows/ios-ci.yml` – Build, Tests, Screenshots auf GitHub-Macs (kein eigener Mac nötig)
- `.claude/` – Studio-Skills und Agenten (aus dem sommerlabs iOS Studio übernommen)
